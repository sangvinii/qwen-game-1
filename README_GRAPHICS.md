# 🌍 Evolution World Simulator - SFML Graphics Version

## ✅ Графика успешно реализована!

Проект теперь использует **SFML** для графической визуализации эволюционного мира.

## 🎮 Что видно на экране:

### Визуальные элементы:
- **Зелёные квадраты** 🟩 - Растения (еда для травоядных)
- **Синие круги** 🔵 - Травоядные существа
- **Красные круги** 🔴 - Хищники
- **Размер круга** - Зависит от здоровья существа (больше = здоровее)
- **Белая пелена** ❄️ - Эффект зимы (когда активирована)

### Панель статистики (внизу):
- Текущий тик симуляции
- Количество существ (травоядные/хищники)
- Количество растений
- Рождения и смерти
- Средние показатели ДНК (скорость, агрессия, метаболизм)

### Управление (Режим Бога):
- **W** - Вызвать зиму (замедляет метаболизм, уменьшает еду)
- **M** - Метеорит (уничтожает 1/3 популяции)
- **P** - Добавить растения
- **E** - Добавить травоядных
- **R** - Добавить хищников
- **ESC** - Выход

## 🚀 Запуск:

```bash
cd /workspace/build
./evolution
```

### Реализованные этапы:
1. ✅ База проекта (мир, существа, движение)
2. ✅ Потребности (голод, поиск еды, смерть)

### Требования:
- C++17
- SFML 2.5+

```bash

cmake ..
make
./evolution
```

## 📊 Наблюдаемые явления:

- **Естественный отбор**: Быстрые и умные существа выживают чаще
- **Эволюция хищников**: Агрессивные ДНК распространяются при избытке жертв
- **Баланс экосистемы**: Хищники вымирают без травоядных

# 🌍 Evolution World Simulator

Полноценная симуляция эволюционного мира с существами, экосистемой, катастрофами и режимом Бога.

## ✅ Реализованные этапы

### Этап 1 — База проекта
- ✅ Класс `World` с картой и размерами
- ✅ Класс `Entity` с позицией, здоровьем, энергией, скоростью
- ✅ Класс `Simulation` для обновления мира
- ✅ Случайное движение существ

### Этап 2 — Потребности существ
- ✅ Голод (энергия уменьшается каждый ход)
- ✅ Поиск еды (алгоритм поиска в радиусе зрения)
- ✅ Смерть от голода/старости

### Этап 3 — ДНК существ
```cpp
struct DNA {
    int speed;        // 1-10
    int vision;       // 1-5
    int aggression;   // 0-10
    int metabolism;   // 1-10
};
```
- ✅ Мутации при размножении

### Этап 4 — Размножение
- ✅ Размножение при высокой энергии (>70)
- ✅ Мутации: `child.stat = parent.stat + random(-1,1)`
- ✅ Эволюция через поколения

### Этап 5 — Поведение
- ✅ Три типа существ:
  - **h** - Травоядные (aggression ≤ 3)
  - **C** - Хищники (aggression ≥ 7)
  - **o** - Всеядные (остальные)
- ✅ Система решений:
  - Если голоден → искать еду
  - Если видит еду → идти к ней
  - Иначе → случайное движение
- ✅ Атака хищников на травоядных

### Этап 6 — Экосистема
- ✅ Растения (`*`) растут и дают энергию
- ✅ Пищевая цепочка:
  - Травоядные едят растения
  - Хищники едят травоядных
  - Всеядные едят всё

### Этап 7 — Графика (текстовая)
- ✅ ASCII-отрисовка мира
- ✅ Символы: `h`=травоядное, `C`=хищник, `o`=всеядное, `*`=растение

### Этап 8 — Катастрофы
- ✅ **Зима** - дополнительный расход энергии
- ✅ **Метеорит** - убивает 1/3 популяции
- ✅ Автоматические события в симуляции

### Этап 9 — Статистика
- ✅ Запись статистики каждый тик:
  - Количество особей по типам
  - Средняя скорость, агрессия, метаболизм
  - Количество растений
- ✅ Сохранение в CSV файл (`evolution_stats.csv`)
- ✅ Финальный отчёт

### Этап 10 — Режим Бога
- ✅ `triggerWinter(duration)` - вызвать зиму
- ✅ `triggerMeteor()` - вызвать метеорит
- ✅ `addEntities(count)` - добавить существ
- ✅ `addResources(count)` - добавить растения
- ✅ `setClimate(factor)` - изменить климат

## 🚀 Сборка и запуск

```bash
cd /workspace
mkdir -p build && cd build
cmake ..
make -j4
./evolution
```

## 🎮 Управление

Симуляция запускается в автоматическом режиме на 100 тиков.

Для интерактивного режима измените в `main.cpp`:
```cpp
bool autoMode = false;
```

Команды в интерактивном режиме:
- **Enter** - следующий шаг
- **w** - вызвать зиму
- **m** - вызвать метеорит
- **a** - добавить 5 существ
- **r** - добавить 10 растений
- **q** - выход

## 🔬 Наблюдаемая эволюция

Через несколько поколений можно увидеть:
- Увеличение средней скорости у выживших
- Изменение агрессии в зависимости от условий
- Адаптация метаболизма к доступности ресурсов
- Вымирание хищников при недостатке травоядных
- Баланс экосистемы
